Sobre o projeto

Confeitarias artesanais geralmente controlam pedidos por meio de anotações manuais ou planilhas, o que dificulta o planejamento da produção e causa atrasos e desperdício de ingredientes.

Este projeto propõe um sistema web que gerencia pedidos e calcula automaticamente a produção diária necessária, com base nas datas de entrega, receitas cadastradas e volume de pedidos.

Proposta

O sistema integra cadastro de clientes, pedidos, produtos e receitas com um motor de planejamento automatizado: a partir dos pedidos e datas de entrega, calcula o que deve ser produzido em cada dia e a quantidade exata de ingredientes necessários. Inclui também um painel administrativo com produção diária, pedidos futuros e estimativa de faturamento.

Funcionalidades planejadas


Autenticação segura de usuários
Cadastro de clientes e pedidos com datas de entrega
Cadastro de produtos e receitas
Cálculo automático da produção diária e dos ingredientes necessários
Painel administrativo com indicadores de produção e faturamento


Diferencial

O principal diferencial é o algoritmo de cálculo automático da produção diária, que considera o ciclo produtivo completo — algo que soluções comerciais (Square POS, Toast POS, Lightspeed Retail) não oferecem.

Tecnologias


Front-end: React.js
Back-end: Node.js + Express.js (API REST)
Banco de dados: MySQL
